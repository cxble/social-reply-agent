# Jev routes replies; it never writes them

Reply selection is a decision made by Jev, not text generated by a language model.

Jev is TypeSafe's System One model. It takes a state plus typed questions and returns one typed answer per question, drawn only from the options supplied to it. It has no text-generation mode at all. This was chosen over the obvious design, in which a model is prompted with the Comment and writes a Reply, for one reason: a Router that cannot generate cannot invent. Every Reply that reaches a Post is text the user approved in advance.

**Consequences.**

- The Router's accuracy is a threshold problem, not an accuracy problem. Jev reports a calibrated confidence, so a low-confidence Comment goes to the Tail rather than being answered wrongly. Treat roughly 68% as the honest prior on a new task.
- The Tail is the only place a Reply can be written from scratch, and so the only place the agent can say something new in public. That is why it is gated by Evaluators, and why the Evaluators are themselves typed questions rather than free-form judges: a verdict is a decision, which is the shape Jev already returns.
- Jev is reached through OpenRouter, which serves it on a Decisions API shared by roughly 27 models from several vendors. Swapping the Router is a change of one model string, and that is what makes a very new vendor acceptable here.
