# social-reply-agent

A fully automated comment-section replying agent for multiple social
platforms, built on browser automation with no official platform APIs.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues, via the `gh` CLI.
See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using the default label strings.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` plus `docs/adr/` at the repo root.
See `docs/agents/domain.md`.
